## 8. 작가의 의견으로 제안이 바뀐 지점

기록해 두는 이유는 방향 판단의 근거가 되기 때문이다.

1. **회차 → 주차 루프**: 상태를 가지고 돌아간다. 회차 설계가 필요 없어졌다.
2. **엄격한 결정론 → 인과와 개입의 분리**: 인과는 상태 의존이고 이벤트는 다른 개념이다. 이는 "인과관계를 경험한다"는 목표와도 맞는다.
3. **장소별 강도 저장 → 거리 기반 파생값**: 저장 상태가 줄었다.
4. **문 조작 → 문 자동**: 플레이어 조작 부담이 줄고 환경 요인과 연결할 여지가 생겼다.
