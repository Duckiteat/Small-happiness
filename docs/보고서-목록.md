## 4. 자동 생성 보고서

| 이름 | 만드는 명령 | 위치 |
|---|---|---|
| 패치 보고서 | `validate`, `merge` (다시 보기: `report <기록>`) | 화면 출력. 통과한 패치는 패치 기록의 `report`에 저장 |
| 자동 생성 부록 | `appendix --write` | `docs/자동생성-부록.md` (`appendix --check`가 최신 여부 확인) |
| 원인 빈칸 · 한계 등록부 | `gaps --write` (원본 `data/limitations.json` + 영수증) | `docs/원인-빈칸.md`, `docs/한계-등록부.md` (`gaps --check`) |
| 시제품(웹) 동기 | `web --write` | `web/` (`web --check`) |

## 8. 목록 관리

- 새 문서를 `docs/`에 만들면 이 목록의 2장에 행을 더한다. 시험이 확인한다.
- **2장 표의 첫 칸만** 백틱 `` `파일명.md` ``(docs 기준 경로)로 쓴다. 루트 파일은 `` `/파일명.md` ``. 다른 표에서는 문서 이름을 백틱 없이 쓴다 (시험이 첫 칸의 백틱 이름만 센다).
- 문서의 상태가 바뀌면 이 표를 같은 커밋에서 고친다.
