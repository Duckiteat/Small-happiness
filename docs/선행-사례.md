## 4. 이 사례들에서 가져온 것

1. 오브젝트가 제공 행동을 소유한다 (Sims의 광고) → `상호작용-명세.md` 3
2. 여유 증감에 원인 이름표를 붙인다 (RimWorld의 생각) → 인물-명세, 21A
3. 문장 선택은 가장 구체적으로 맞는 것 우선 (salience) → 기획 보고서 5
4. 상호작용은 같은 장소나 인접 장소 안에서 (Inform의 방 범위) → 세계-설정 6

## 5. 한국어 어휘 자원 (어휘집 후보, 구현 계획 33)

2026-11-03 검색으로 확인한 범위다. **라이선스는 어느 것도 확인하지 못했다.** 쓰기 전에 공식 배포처에서 직접 확인해야 한다.

| 자원 | 확인한 것 | 확인하지 못한 것 |
|---|---|---|
| 한국어기초사전 (국립국어원) | 한국어 학습에 기본이 되는 약 5만 어휘 (2016 보도) | 현재 규모, 학습용 어휘 "목록"의 개수, 정확한 이용 조건 |
| 우리말샘 (국립국어원) | 개통 당시 표준국어대사전 50만 + 새 50만 = 약 100만 어휘 (2016 보도). 국립국어원이 "저작권을 개방한다"고 밝힘 | 공식 페이지의 라이선스 조건 (CC BY-SA 2.0 KR을 명시한 것은 제3자 데이터셋뿐이며 공식이 아님) |

| Kiwi (형태소 분석기) | C++, wasm으로 브라우저 실행 가능, 모델 16/40/90MB, LGPL v3, 모호성 해소 정확도 약 87%(웹)·94%(문어) | 용언 활용의 원형 복원 방식, MeCab-ko와의 비교 |

- 1만~2만 어휘는 위 자원의 규모에 비해 **작은 부분집합**이다. 어떤 기준으로 고를지가 먼저다.
- 한국어는 동음이의가 많고 용언이 활용하며 조사가 붙는다. 어휘집은 표제어에 어깨번호(배01, 배02)를 두어 동음이의를 구분해야 하고, 문장 속 단어를 표제어로 되돌리는 데는 형태소 분석이 필요하다. 분석 정확도가 100%가 아니므로 관문의 **하드 게이트로는 부적합**하고 경고 수준에 둔다.
