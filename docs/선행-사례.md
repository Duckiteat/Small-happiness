## 2. 설계 원리의 선행 사례

| 분야 | 그쪽의 틀 | 우리와의 관계 | 확인 수준 |
|---|---|---|---|
| **Inform 7** (텍스트 어드벤처) | 방, 방 사이의 연결(방향·문), 물건. 문은 열림/잠김 상태를 가진 물건. 물건은 방 안에 있거나 무대 밖에 있고, 다른 방의 것과는 기본적으로 상호작용하지 못함 | 장소 그래프와 통로, "삭제 없이 보관"(무대 밖), 상호작용은 같은 장소·인접만 | 검색으로 확인 ([매뉴얼 §24](https://www.inform-fiction.org/manual/html/s24.html), [핸드북](https://inform-7-handbook.readthedocs.io/en/latest/chapter_3_things/containers_&_supporters/)) |
| **Storylets / 품질 기반 서사** | 이야기 조각이 상태(품질)에 걸린 조건으로 열림. 작고 독립적이며 재조합이 쉬움 | 이벤트 = 조건이 붙은 독립 단위, 분기는 추가만 | 개념은 확인 ([Emily Short](https://emshort.blog/2016/04/12/beyond-branching-quality-based-and-salience-based-narrative-structures/), [Yarn Spinner](https://docs.yarnspinner.dev/write-yarn-scripts/advanced-scripting/storylets-and-saliency-a-primer)). "기존 수정 없이 추가된다"는 문장 자체는 직접 확인 못 함. Failbetter는 QBN 명칭을 더 쓰지 않음 |
| **RimWorld** | 기분은 여러 생각의 합, 임계 아래로 떨어지면 정신 붕괴(기본 경미 35%·심각 20%·극단 5%, 성향이 이동), 수면 중에는 멈춤 | 모드와 임계, 인물 성향이 임계를 바꿈, 여유 증감의 원인 이름표 | 기분·붕괴 임계는 확인 ([위키](https://www.rimworldwiki.com/wiki/Mental_Break_Threshold)). 방의 청결·온도 효과와 이야기꾼은 확인 못 함. 붕괴 빈도는 출처마다 다름 |
| **The Sims** | 욕구(motive)가 행동을 정하고 물건이 자기 효과를 "광고". 물건을 나중에 추가해도 광고만 맞으면 쓰임 | 자율 행동 점수, 오브젝트가 `offers`를 소유 | 검색으로 확인 ([Wikipedia](https://en.wikipedia.org/wiki/The_Sims_(video_game)), [GMTK 자막](https://amara.org/subtitles/cVoJS4OdmVql/en/1/download/The%20Genius%20AI%20Behind%20The%20Sims.en.txt)). 일부 출처는 약함 |
| **CONTAM** (NIST) | 건물을 구역으로 나누고 흐름 경로(저항)로 잇고, 바람·압력차가 구동력 | 장소 그래프 + 통로 투과율 + 공기 매질 | 구역·경로 구조는 확인 ([NISTIR 5440](https://nvlpubs.nist.gov/nistpubs/Legacy/IR/nistir5440.pdf)). 문·창문·환기 횟수 세부는 확인 못 함 |

## 3. 더 파볼 만한 곳 (확인 안 함, 기억에 의존)

- 건축의 **공간 구문론**: 주거 평면을 접근 그래프로 분석
- **Dwarf Fortress / Oxygen Not Included**: 기체·온도 확산
- **Façade**: 비트 단위 극 관리
- **스트레치텍스트 / Twine**: 문장이 제자리에서 펼쳐지는 하이퍼텍스트

## 4. 이 사례들에서 가져온 것

1. 오브젝트가 제공 행동을 소유한다 (Sims의 광고) → `상호작용-명세.md` 3
2. 여유 증감에 원인 이름표를 붙인다 (RimWorld의 생각) → 인물-명세, 21A
3. 문장 선택은 가장 구체적으로 맞는 것 우선 (salience) → 기획 보고서 5
4. 상호작용은 같은 장소나 인접 장소 안에서 (Inform의 방 범위) → 세계-설정 6
