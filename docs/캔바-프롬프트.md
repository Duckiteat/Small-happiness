# 캔바 프롬프트

화면 계약(`화면-계약.md`)의 첫 장면 여섯 상태를 캔바에서 디자인하기 위한 프롬프트다. 작성일 2026-11-03.

## 먼저 알아둘 것 (검색으로 확인한 범위)

- 캔바 한국어 공식 페이지에는 **Magic Design이 아직 회원님의 언어로 제공되지 않는다**고 안내되어 있다. 그래서 프롬프트는 **영어**로 쓰고 한국어 문구만 따옴표 안에 정확히 넣었다. 필요하면 계정 언어를 영어로 바꾼다. 최신 상태는 캔바에서 직접 확인해야 한다.
- 내보내기는 PNG·SVG·PDF가 가능하다. **투명 배경 SVG는 유료 요금제(Pro 등)** 에서 쓸 수 있다고 한다. 개발자 문서에는 PNG·SVG가 다중 페이지 내보내기를 지원하지 않는다고 되어 있으므로, **전체 페이지는 PDF**로 받는 것이 안전하다.
- 생성된 요소의 이름 지정·레이어 구조는 **확인하지 못했다.** 그래서 "구조"를 레이어 이름이 아니라 **모든 페이지에서 같은 슬롯에 같은 요소를 두는 규칙**으로 요청한다.
- 캔바의 결과는 **시각 기준**이다. 받으면 이미지를 읽어 이 문서의 슬롯 표와 대조한 뒤, 같은 구조를 HTML/SVG로 다시 짜서 뷰 모델 JSON에 붙인다. 캔바가 글자나 위치를 틀리게 만들어도 이 문서와 JSON이 기준이다.

## 1. 마스터 프롬프트 (7페이지, 데스크톱 16:9)

캔바 Magic Design(또는 AI 디자인)에 그대로 붙여 넣는다. `[ ]`는 눌리는 단어를 뜻하고, 캔바에게 그렇게 설명되어 있다.

```
Create a 7-page design in 16:9 landscape (1920x1080). It is a UI storyboard for a quiet, text-first Korean life-simulation game. Pages 1-6 show ONE scene as six consecutive states of the same screen; page 7 is a legend. Keep the canvas, margins, grid and fonts identical on every page, and keep every element in the same position from page to page unless a page says otherwise.

STYLE (adjustable): calm paper-like off-white background, hand-drawn ink lines with a pencil or ink-pen feel (slightly imperfect), one muted accent color, a lot of white space. The prose is the hero; the map is a margin note. All Korean text must be exactly as given below: do not translate, rewrite, shorten or add text. No stock photos and no decorative icons. Never use color as the only way to tell things apart; also use line style, shape and weight.

LAYOUT: the left 60% is the "prose zone": Korean story text, large, generous line spacing, a readable Korean serif or soft sans-serif. The right 40% is the "map zone", which has an invisible 3x3 slot grid (columns L, C, R; rows T, M, B; do not draw the grid). A small caption in the top-left of every page shows the place name and the page code, for example "현관 · 01-arrive".

VISUAL VOCABULARY (use consistently):
- Clickable word: a word inside the prose with a thin dotted underline.
- Open circle: a hand-drawn loop around a clickable word that does NOT quite close (a small visible gap, about 300 degrees).
- Closed circle: the same loop fully closed.
- Perception node: a rounded oval label in the map zone.
- Action node: a pill- or tab-shaped label with a clearly different silhouette from the perception node.
- Ghost node: a dashed outline containing only "…", with a small italic caption beneath it.
- Lines: solid thin line = known link; solid line with a small dot at the choice end = selectable option; dotted line = suspected link.
- Node states: new = slightly bolder stroke with a small tick mark; seen = normal; done = lighter with a small check mark; faded = barely visible faint trace.
- Core vs periphery: the core perception node sits at the center of the map zone and is the largest; peripheral nodes sit around it and are smaller.
- Show at most 5 visible nodes on any page.

SLOTS in the map zone: M-C = center; T-R, M-R, B-R = right column (top, middle, bottom); T-L, B-L = left column; B-C = bottom center. Always use the same slot for the same node on every page.

PAGES. Text in quotes is exact Korean. Square brackets [ ] mark a clickable word (dotted underline); do not print the brackets.

Page 1, code "01-arrive", place "현관".
Prose, one paragraph: 현관문을 열자 [꼬릿한 냄새?] 가 났다.
Map zone empty. No circles.

Page 2, code "02-circle", place "현관".
Same prose. An OPEN circle around [꼬릿한 냄새?]. A solid thin line from that circle to the center perception node "꼬릿한 냄새?" (slot M-C). Two action nodes with option lines from the center node: "킁킁" (slot T-R) and "지나친다" (slot B-R). All three nodes are "new".

Page 3, code "03-guess", place "현관".
Prose gets a second paragraph: 킁킁. [어디지.] 근데 은근 구수하네.
The first clickable word keeps its OPEN circle; [어디지.] has no circle. The center node (slot M-C, same shape) now reads "구수한가? 상한 건가?". "킁킁" (T-R) is "done". "지나친다" (B-R) is "faded". New action nodes from the center node: "주위를 둘러본다" (slot M-R) and "창문을 연다" (slot B-C).

Page 4, code "04-thing", place "주방".
Prose gets a third paragraph: 주방 쪽이다. 냉장고 문틈으로 [허옇게 뭉개진 것]이 보인다.
The first and second clickable words have OPEN circles; the third has none. The center node now reads "상한 두부" and is the largest and most emphasized (core). Peripheral perception nodes: "냄새" (slot B-L) joined to the center by a solid thin line, and "벌레?" (slot T-L) joined to the center by a DOTTED line. Action nodes: "버린다" (slot M-R, option line from the center node) and "창문을 연다" (slot B-C, option line from "냄새"). Exactly 5 visible nodes; earlier action nodes are gone or barely visible.

Page 5, code "05-closed", place "주방".
Prose gets a fourth paragraph with no clickable word: 두부를 봉지에 넣어 묶었다. 냄새가 한결 가볍다.
All three clickable words now have CLOSED circles. The nodes "상한 두부" (M-C), "냄새" (B-L) and "버린다" (M-R) are "done" (check marks). No other nodes.

Page 6, code "06-cold", place "현관".
Prose, one paragraph with no clickable word: 현관문을 열었다. 코가 꽉 막혀 있다.
Map zone: only a ghost node "…" at slot M-C, with the italic caption "머리가 무겁다". No lines.

Page 7, code "legend".
A clean legend that shows every element above, each with a short English label and a Korean label: clickable word "눌리는 단어", open circle "열린 동그라미", closed circle "닫힌 동그라미", perception node "지각 노드", action node "행동 노드", ghost node "못 뜬 생각", known link "알고 있는 연결", selectable option "고를 수 있는 길", suspected link "의심하는 연결", node states "새로" / "보임" / "끝남" / "희미해짐", core "핵심", periphery "주변부".

Finally, make sure all pages share identical margins and fonts, and that each page's code is visible in its top-left caption.
```

## 3. 결과를 고치는 후속 프롬프트

캔바가 한 번에 맞게 만들지 못하면 이어서 하나씩 보낸다.

```
On pages 2, 3 and 4 the circle around the clickable word must look hand-drawn and clearly OPEN, with a visible gap. On page 5 the same circles must be fully CLOSED.
```
```
The Korean text must be exactly as I gave it. Restore any text you changed or removed. Do not add any new text anywhere except the page-code captions and the legend labels.
```
```
Keep every node in the same slot on every page, as in the slot table: center node at M-C, "킁킁" at T-R, "지나친다" at B-R, "주위를 둘러본다" and "버린다" at M-R, "창문을 연다" at B-C, "냄새" at B-L, "벌레?" at T-L.
```
```
Make the action nodes (pill shape) look clearly different from the perception nodes (oval) and make the dotted line on page 4 clearly different from the solid lines, without relying on color.
```
```
Reduce decoration. The prose must remain the strongest element on the page and the map should look like quiet margin notes.
```

```
Using the same six states and the same Korean text, create a 9:16 portrait version (1080x1920) of pages 1-6 plus the legend. Put the prose zone in the top 62% and the map zone in the bottom 38%, with the same invisible 3x3 slot grid in the map zone and the same slot for each node as before. Keep the same visual vocabulary. ## 5. 받는 방법
```

1. 전체 페이지를 **PDF**로 내보낸다. 가능하면 각 페이지를 **PNG**로도 받는다 (파일 이름은 페이지 코드 `01-arrive` … `06-cold`, `legend`).
2. 유료 요금제라면 SVG도 받아 둔다 (확인: 투명 배경 SVG는 Pro 등 유료).
3. 받은 파일을 저장소의 `design/` 폴더에 넣거나 채팅에 올린다.
4. 저는 이미지를 읽어 슬롯 표와 `examples/view/` JSON에 맞는지 대조하고, 어긋난 곳(글자, 위치, 노드 수)을 알려 드린 뒤, 같은 구조를 HTML/SVG로 다시 짠다.

## 6. 확인하지 못한 것

- Magic Design이 한국어 문구를 정확히 넣는지, 영어 UI에서 한국어 폰트를 제대로 쓰는지
- 캔바가 슬롯 위치와 "열린 원 / 닫힌 원"의 차이를 지키는지 (그리지 못하면 범례와 한 페이지씩 수동으로 보정해야 할 수 있다)
- 생성된 요소의 이름·레이어 구조
- 최신 요금제별 내보내기 제한
