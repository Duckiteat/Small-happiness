## 3. 냄새의 원인 사슬

원인의 단계 → 균주 → 유기화합물 → 냄새 종류. 사전 `odor_cause`·`strain`·`compound`·`odor_kind`에서 계산한 것이고, 대표 냄새는 가장 심각한 종류다. 서지로 확인하지 않은 지식이다 (`verified: false`).

- 부패 · 쉼: 젖산균 → 아세트산 → 시큼한 발효 냄새 · 세기 은은함
- 부패 · 상함: 슈도모나스 · 장내세균과 → 디메틸 이황화물 · 메탄티올 · 황화수소 · 푸트레신 · 카다베린 · 인돌 → 썩는 냄새 (황 냄새도 섞임) · 세기 뚜렷함
- 부패 · 썩음: 장내세균과 · 클로스트리디움 → 황화수소 · 푸트레신 · 카다베린 · 인돌 · 부티르산 → 썩는 냄새 (황 냄새도 섞임) · 세기 지독함
- 시어짐 · 시큼: 젖산균 → 아세트산 → 시큼한 발효 냄새 · 세기 은은함
- 시어짐 · 덩어리짐: 젖산균 · 슈도모나스 → 아세트산 · 디메틸 이황화물 · 메탄티올 → 황 냄새 (시큼한 발효 냄새도 섞임) · 세기 뚜렷함
- 익음 · 시어짐: 젖산균 → 아세트산 → 시큼한 발효 냄새 · 세기 은은함
- 익음 · 물러짐: 젖산균 · 슈도모나스 → 아세트산 · 디메틸 이황화물 · 메탄티올 → 황 냄새 (시큼한 발효 냄새도 섞임) · 세기 뚜렷함
- 시듦 · 쭈글·짓무름: 슈도모나스 · 장내세균과 → 디메틸 이황화물 · 메탄티올 · 황화수소 · 푸트레신 · 카다베린 · 인돌 → 썩는 냄새 (황 냄새도 섞임) · 세기 은은함
- 곰팡이 · 번짐: 곰팡이류 → 지오스민 · 1-옥텐-3-올 → 곰팡내 · 세기 은은함
- 요리: 피라진류 · 알릴 이황화물 → 구수함
