# 선행 개념 이식 설계 (아홉 층에 넣을 자리)

작성일 2026-11-06 · 상태: **제안** · 근거: `선행-사례.md` 2·2A장, `축과-층위.md` 3장, `품질판-명세.md`, `상호작용-명세.md` 2A·2C·3, `인물-명세.md` 8, `층-비교.md` 3·5장

다른 곳에서 먼저 만든 개념을 모아, **그쪽은 어떻게 풀었나 / 우리는 지금 어떻게 두었나 / 무엇이 다른가 / 넣는다면 어느 층의 어디에**를 정리한다. 결정하지 않는다. 고를 것은 4장 표와 7장 질문에 모았다.

---

## 0. 결론

- **아홉 층을 이 모양 그대로 만든 사례는 찾지 못했다.** 층마다 닮은 개념은 있다. 가져올 만한 것이 아홉 가지(P1~P9), 일부러 넣지 않을 것이 세 가지(N1~N3)다.
- 우리와 남들의 가장 큰 차이는 세 가지다.
  1. **판의 주인.** 남들의 공용 판(C4의 칠판, Valve의 사실 묶음)은 누구나 읽고 쓴다. 우리 품질판은 이름 공간마다 주인 층이 하나이고, 두 라인(세계·사람)이 5 지각에서야 만난다.
  2. **결정론.** 남들은 연속값(신뢰도, 효용)과 그때그때 굴리는 난수를 흔히 쓴다. 우리는 정수와 단계 키를 쓰고, 난수는 정해진 층에서만 뽑아 저장한다. 가져오는 개념은 모두 **정수·키·저장된 난수**로 바꿔야 한다.
  3. **이야기를 찾는 자리.** 학계의 이야기 거르기(Felt·Winnow)는 시뮬레이션이 끝난 기록을 **밖에서** 거른다. 우리는 7층이 **같은 단계 안에서** 품질판만 보고 장면을 연다. 그리고 우리 7층은 아직 **사건의 순서**를 보지 않는다. 이 점이 가장 크게 다르다.
- 권장 순서: P1 구체성 선택 부품 → P2 대상별 지각 기억 → P3 출처 이름표 → P4 단계 있는 장면 → 나머지. 1~4는 이미 있는 작업(14B, 19, 19A, 19B, 20)에 들어가므로 새 작업을 만들지 않는다.

---

## 1. 문제

- 층마다 "어떻게 계산하나"가 비어 있다 (뼈대 `src/core/skeleton.ts`의 3~8층은 중립값이다).
- 비슷한 문제를 이미 푼 곳이 있다. 그대로 베끼면 우리 원칙(주인 하나, 결정론, 결과를 직접 정하지 않음)과 부딪힌다. 무엇을 바꿔서 가져올지를 먼저 정해야 한다.

## 2. 사례별 비교

확인 수준은 `선행-사례.md` 2A장에 있다. "제 해석"이라고 쓴 칸은 원문을 다 읽지 않고 정리한 것이다.

### 2-1. C4 (MIT, Isla·Burke·Blumberg 2001) → 5 지각

| | |
|---|---|
| 그쪽 해석 | 뇌를 지각·기억·주의·행동 선택·운동 체계로 나누고, 체계끼리 **공용 칠판**으로 주고받는다. 지각은 **지각 트리**(감각 → 점점 구체적인 지각)이고, 켜진 지각의 신뢰도를 **대상마다 기억 묶음**(PerceptMemory)에 담는다. 새 지각은 가장 비슷한 기존 묶음에 붙는다. 묶음은 대상이 안 보여도 남는다(**대상 지속성**). 마지막 위치와 자기 움직임으로 위치를 예측한다 |
| 우리 지금 | 품질판이 칠판 역할을 한다. 5층이 `perceived`·`aware`·`memory`를 쓴다. 감각마다 주는 정보의 종류(존재·위치·정체·정도)가 `상호작용-명세.md` 2A-2에 있다. **대상별 묶음은 아직 없다** (`aware`의 모양이 정해지지 않았다) |
| 다른 점 | ① 칠판은 공용이고, 품질판은 주인이 하나다. ② 신뢰도는 실수이고 줄어드는 값이다. 우리는 인지 사다리 **키**(모름 → 알아챔 → 이해함)다. ③ C4는 "같은 대상인가"를 비슷함으로 맞춘다. 우리는 세계의 번호가 있으므로 맞출 필요가 없다. 다만 **하루씨가 모르는 번호를 쓰면 안 된다** (정체를 모르는 단계) |
| 넣을 것 | **P2 대상별 지각 기억.** `aware`를 대상 번호 → `{ step, senses, last_seen_t, last_seen_place, last_seen_level }`로 둔다. 정체를 모르는 단계에서는 대상 번호 대신 **자극 원천 키**(`world.stimulus_source`의 키)를 쓴다. "마지막으로 본 단계"는 13 부재 보정의 상한(마지막으로 본 상태 +1단계)과 같은 값이므로 한 곳에 둔다 |

### 2-2. The Sims (Wright, 2000) → 6 행동

| | |
|---|---|
| 그쪽 해석 | 사람은 단순하게, 물건은 똑똑하게 만든다. 물건이 "나를 쓰면 이 욕구가 이만큼 찬다"고 **광고**하고, 욕구가 낮을수록 강한 광고를 고른다. 욕구마다 **곡선**이 따로 있다 (급한 욕구는 가파르다). 교훈: 초기판은 자율이 너무 잘해서 플레이어의 개입이 대부분 손해였다 |
| 우리 지금 | 물건의 `offers`(`상호작용-명세.md` 3), 점수식 `Σ(욕구 × 해소) + 습관 + 취향 − 비용`(`인물-명세.md` 8). 후보는 **알아챈 물건**뿐이다 |
| 다른 점 | ① Sims는 근처 광고가 모두 후보다. 우리는 5 지각을 거친 것만 후보다. 플레이어가 하루씨보다 많이 보는 극적 아이러니가 여기서 나온다. ② Sims의 욕구 곡선은 비선형이다. 우리 식은 욕구 강도를 그대로 곱한다. ③ 거리에 따른 감쇠는 확인하지 못했다 |
| 넣을 것 | **P6 욕구 긴급도 표.** 욕구의 단계 키 → 정수 가중(×100) 표를 인물 정의에 둔다. 14A 조절 규칙의 한 경우로 처리하면 새 장치가 필요 없다. 수치는 `tuned:false`다. **교훈은 시험으로 이미 있다**: 16 앙상블의 "돕는 정책의 여유 평균이 더 높다"가 Sims의 실패를 막는 기준이다 |

### 2-3. Versu (Evans·Short, 2013~2014) → 6 행동 (+ 7)

| | |
|---|---|
| 그쪽 해석 | **사회적 관행**(social practice): 되풀이되는 상황(식사, 대화)을 역할·상태·제공 행동을 가진 단위로 쓴다. 관행은 누가 어느 역할을 맡는지 모르게 쓴다. 행위자는 관행이 제공한 행동 중 **효용**이 가장 높은 것을 고른다. **연출가**는 몸 없는 행위자이거나 특별한 관행이다. 직접 조종하지 않고 제안만 하거나, 가끔 어떤 인물의 욕구를 낮춘다. 상태는 **배타 논리**(한 자리에 값 하나)로 저장한다 |
| 우리 지금 | 행동을 제공하는 것은 **물건**뿐이다. 상황 단위가 없다 (일과는 인물 정의에 있다). 연출가는 없다. 모드의 빈도는 "작가의 연출 값이고 시스템이 정하지 않고 검증한다"(`인물-명세.md` 6) |
| 다른 점 | ① Versu에서는 상황이 행동을 광고하고, 우리는 물건이 광고한다. ② 배타 논리는 우리의 "특징마다 단계 키 하나" 저장(9 세계 상태)과 같은 발상이다. ③ Versu는 연출가가 욕구를 움직여 이야기를 끌고, 우리는 끌지 않고 **검증만** 한다 |
| 넣을 것 | **P7 상황 단위의 제공 행동.** 귀가·식사·잠들기 같은 상황이 `offers`를 갖는 정의 종류를 둔다 (역할은 지금 하루씨 하나). 귀가 장면이 가장 중요한 장면이므로(`인물-명세.md` 7) 쓸 곳이 분명하다. 새 정의 종류라서 **작가 결정이 필요하다**. 연출가는 N2로 넣지 않는다 |

### 2-4. Valve 동적 대사 (Ruskin, GDC 2012) + Inform 7 규칙 정렬 → 7 이벤트, 8 표현

| | |
|---|---|
| 그쪽 해석 | 질의는 화자·세계·기억의 **사실을 평평하게 모은 것**이다. 규칙은 조건 목록이다. **조건이 가장 많이 맞는 규칙이 이기고**, 일반 규칙이 기본값이 된다. 없는 사실을 언급하는 규칙은 떨어진다. 동률은 무작위다 (2차 출처). 대사가 끝나면 **기억을 쓰고**(만료 가능), 후속 규칙을 찾고, 한 번 쓴 규칙은 스스로 빠질 수 있다. Inform 7도 같은 원리다. 조건 절의 수로 구체성을 재고, 더 구체적인 규칙이 먼저 돈다 |
| 우리 지금 | `층-비교.md` 2장: 7·8은 "조건이 더 많이 맞는 것이 먼저 + 일반 기본값". 5-4 권장: 선택 부품 하나를 5·6·7·8이 같이 쓴다. 8층은 **읽기 전용**이다. 난수는 문장 변주에만 쓴다 |
| 다른 점 | ① 원리가 같다. 남은 것은 **구체성을 무엇으로 재는가**(조건 수? 가중?)와 **동점 규칙**이다. ② Valve는 대사가 상태(기억)를 바꾼다. 우리 8층은 아무것도 쓰지 않는다. 그래서 **같은 문장의 반복을 막을 길이 지금 없다** (이번에 찾은 문제) |
| 넣을 것 | **P1 구체성 선택 부품.** 구체성은 맞은 조건의 수로 잰다. 동점이면 ① 작가가 준 우선순위 → ② 그 층에 난수가 허용되면 저장된 난수 → ③ 정의 번호 순으로 고른다. 없는 품질을 언급한 후보는 떨어진다 (중립 기본값과 충돌하지 않게: 중립값은 "있음"으로 본다). 14B·19A·20이 같이 쓴다. **P8 문장 반복 방지**는 8층이 읽기 전용이라 바로 넣을 수 없다. 7장 질문 2 |

### 2-5. 품질 기반·현저성 기반 서사 (Failbetter, Short 2016) → 7 이벤트, 2B 줄글

| | |
|---|---|
| 그쪽 해석 | 품질 기반(QBN): 조건이 맞는 이야기 조각들 중에서 **플레이어가 고른다**. 현저성 기반(SBN): **시스템이** 지금 가장 맞는 조각을 고른다 |
| 우리 지금 | 7층 장면 포착은 SBN이다. 2B 줄글의 링크(눌러서 주의를 돌림)는 QBN이다 |
| 다른 점 | 두 방식을 층으로 나눠 같이 쓴다. 남들은 대개 한쪽을 고른다 |
| 넣을 것 | 새로 넣을 것은 없다. 이름만 맞춘다 (7 = 시스템이 고름, 6에 들어오는 플레이어의 주의 = 플레이어가 고름) |

### 2-6. 이야기 거르기: Felt·Winnow (Kreminski 외, 2019~2021) → 7 이벤트

| | |
|---|---|
| 그쪽 해석 | 시뮬레이션의 **사건 기록**에서 이야기가 될 **사건의 순서**(예: 모욕 → 앙심 → 방화)를 질의로 찾는다. Felt는 Datalog 부분집합으로 돌고, 다 끝난 기록에서 찾는다. Winnow는 패턴을 **단계**로 쓰고, **부분 일치의 웅덩이**를 들고 있다가 새 사건이 올 때마다 맞춰 본다. `unless` 절이 오면(예: 인물이 죽음) 부분 일치를 버린다. 앞 단계만 일어난 부분 일치를 보고, 생성기가 나머지를 이어 가게 할 수 있다 |
| 우리 지금 | 7층은 지금 품질판에 대한 희소 조건이다. **순서를 보지 않는다.** 그런데 장면에는 이미 수명이 있다: 열림 → 처리 → 닫힘 또는 연쇄(`상호작용-명세.md` 2A-4). 닫힘 조건은 필수다 |
| 다른 점 | ① 그쪽은 기록을 밖에서 거르고, 우리는 단계 안에서 연다. ② 그쪽은 순서를 보고, 우리는 지금 상태를 본다. ③ 제 해석: 우리 "열린 장면"이 Winnow의 부분 일치, "연쇄"가 다음 단계, "닫힘 조건"이 `unless`와 같은 모양이다. 이미 반쯤 같은 구조다 |
| 넣을 것 | **P4 단계 있는 장면.** 장면 정의에 `stages`(순서 있는 조건 목록)를 허용한다. 열린 장면과 그 장면이 몇 번째 단계까지 왔는지를 `scene`에 저장한다. 7층은 기록을 직접 읽지 않으므로, 순서 조건은 **품질판에 오른 것**(`recent`의 행동, `aware`의 단계 변화, `memory`)으로만 쓴다. 난수는 쓰지 않는다. 직전 단계의 `scene`을 7이 읽어야 하므로 **되먹임 길이 하나 늘어난다** (F5: 7 → 7, 자기 이월). 7장 질문 3 |

### 2-7. Talk of the Town (Ryan·Mateas, 2015~) → 5 지각 (기억)

| | |
|---|---|
| 그쪽 해석 | 인물마다 사람·장소별 **정신 모형**(한 사람에 250~400개)이 있다. 믿음은 세 길로 생긴다: **직접 봄 / 전해 들음**(참이든 거짓이든) **/ 관련 정보에서 옮기거나 지어냄**. 잊고, 잘못 기억하고, 퍼진다. 거짓말도 되풀이하면 믿게 된다. 새 후보 믿음이 지금 믿음을 밀어낼 수 있다 |
| 우리 지금 | 기억은 기록에서 **다시 계산할 수 있는 파생물**이다 (`상호작용-명세.md` 2C-3). 망각에 난수가 없다. 오인은 작가의 선택이다 (2D-3). 인물은 하나다 |
| 다른 점 | ① 그쪽 기억은 따로 저장되는 상태이고 무작위로 변한다. 우리 기억은 파생물이라 지우고 다시 계산하면 같아야 한다. ② 그쪽은 여러 인물 사이의 전파가 핵심이다. 우리는 인물 2명째(31) 이후의 일이다 |
| 넣을 것 | **P3 출처 이름표.** `aware`·`memory` 항목에 `source`(`seen`·`smelled`… 감각 / `told` / `guessed`)를 키로 붙인다. 2C에서 눌러서 물을 때 답의 확신 정도("분명히 봤다" / "그런 것 같다")가 이 이름표에서 나온다. 오인은 무작위 변이가 아니라 **결정적 규칙**(심상 사다리의 `guess` 칸에서 비슷한 후보와 섞임)으로만 둔다. 전파는 31에서 다룬다 |

### 2-8. Façade (Mateas·Stern, 2005) → 7 이벤트

| | |
|---|---|
| 그쪽 해석 | **비트**(전제·효과가 달린 장면 단위)를 연출가가 고른다. 목표 **긴장 곡선**과 지금 긴장을 보고, 서서히 오르다 터지는 극 구조를 만들도록 고른다. 한 번에 비트 하나만 돈다 |
| 우리 지금 | 연출가가 없다. 모드 빈도는 검증한다 |
| 다른 점 | 그쪽은 목표 곡선을 **강제**하고, 우리는 강제하지 않는다 |
| 넣을 것 | **P9 동시에 열린 장면 수 상한**만 가져온다 (14B의 "한 번에 5개"와 같은 모양). 긴장 곡선은 강제하지 않고 25 가설 등록과 21 하루 보고서의 **보고 항목**으로 둔다. 연출가는 N2 |

### 2-9. RimWorld 이야기꾼 → 4a 외부계

| | |
|---|---|
| 그쪽 해석 | 이야기꾼이 플레이어의 상태(재산, 인구, 최근 손실)를 보고 사건의 크기와 빈도를 맞춘다. 적응 계수는 시간이 지나며 오르고 정착민이 죽으면 내려간다. 인구 의도는 인구를 목표 근처에 둔다 (커뮤니티 관찰) |
| 우리 지금 | 4a는 `time`만 읽고 외부 카드를 뽑는다. 외부는 하루씨의 행동에 반응하지 않는다 (`품질판-명세.md` 5장) |
| 다른 점 | 그쪽 외부는 반응하고, 우리 외부는 반응하지 않는다. 라인 분리의 원칙이다 |
| 넣을 것 | **넣지 않는다 (N1).** 넣으려면 4a가 `self`를 읽어야 하고, 두 라인 원칙을 바꿔야 한다. 차이만 기록한다 |

### 2-10. Oxygen Not Included · CONTAM → 3 인과 (번짐)

| | |
|---|---|
| 그쪽 해석 | ONI: 칸마다 원소 하나, 칸은 **이웃만 보고** 갱신하는 세포 자동자다. 압력과 바람은 따로 모형화하지 않는다. 질량·에너지 보존은 엄밀하지 않다는 커뮤니티 논의가 있다 (공식 확인 못 함). CONTAM: 건물을 구역과 흐름 경로로 나눈다 |
| 우리 지금 | 번짐은 장소 그래프(방 단위)와 통로 투과율, 정수, 난수 없음이다. 12 자원은 총량 보존을 시험한다 |
| 다른 점 | 해상도가 다르다 (칸과 방). "이웃만 본다"는 같다. 우리는 보존을 시험으로 강제한다 |
| 넣을 것 | **P5 이웃만 읽기 시험.** 3층 번짐이 한 단계에 통로 하나를 넘어 퍼지지 않음을 시험으로 둔다 (11 번짐의 끝나는 조건에 더함). 칸 해상도는 넣지 않는다 |

### 2-11. Thing Sandbox → 라인 A/B

## 5. 영향

- **품질판 모양**: P2·P3은 `aware`·`memory`의 값 모양을 정한다 (새 이름 공간은 없음). P4는 `scene`의 모양과 되먹임 길(F5)을 바꾼다. 바꾸면 `품질판-명세.md` 5장과 `board.ts`의 `PREV_READS`를 같은 커밋에서 고친다.
- **시험**: 모든 제안은 중립 기본값으로 넣을 수 있어야 한다 (넣기 전과 골든 트레이스가 같음). P1은 "구체적인 것이 이긴다"·"동점은 같은 입력이면 같은 결과" 거부 시험이 필요하다.
- **새 작업 번호**: 만들지 않는다. 모두 기존 작업의 끝나는 조건에 더한다.
