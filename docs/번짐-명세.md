# 번짐 명세 (변화 규칙의 하위 설계, 초안)

오염과 부패가 장소를 넘어 퍼지는 방식을 정의한다. 변화 규칙의 일부이므로 **난수를 쓰지 않는다** (기반층-명세 0-5). 상태: 초안.

---

## 1. 핵심 개념

- 번짐은 상태의 속성이 아니라 **번짐 개체**가 일으킨다. 냄새, 벌레, 먼지, 물, 곰팡이는 각자 번지는 방식과 범위가 다르다.
- 번짐 개체는 하나로 끝나지 않고 **연결**된다. 부패한 음식 하나가 냄새를 내고, 벌레를 부르고, 벌레가 다른 곳에서 번식하고, 습기가 곰팡이를 낳는다. 이 묶음을 **계통**이라 부른다.
- 개체 정의(범위, 매질, 의존, 연결)는 전부 **데이터**다. 엔진은 개체 이름을 모른다.

용어

| 용어 | 뜻 |
|---|---|
| 원천 | 번짐의 근원이 되는 상태 (상한 음식, 젖은 신발) |
| 번짐 개체 | 원천에서 생겨 퍼지는 것 (냄새, 벌레, 오염, 물, 곰팡이) |
| 매질 | 개체가 이동하는 방식 (공기, 운반, 자력 이동, 흐름) |
| 통로 | 장소 그래프의 간선. 개체가 지나갈 수 있는 길 |
| 계통 | 하나의 원천에서 이어져 나오는 개체들의 묶음 |

---

## 2. 장소 그래프

- **노드**는 장소(PLC), **간선**은 통로다.
- 간선은 종류와 상태를 가진다.

| 종류 | 예 | 가변 상태 |
|---|---|---|
| 열린 통로 | 현관-거실 사이 | 없음 |
| 문 | 방문, 냉장고 문 | 열림 / 닫힘 (**플레이어가 바꿈**) |
| 벽 | 방과 방 | 없음 |
| 배수·환기구 | 욕실 배수구, 환풍기 | 막힘 / 열림 |

- 간선마다 **매질별 투과율**(0~1000)을 가진다. 예: 닫힌 문은 공기 100, 자력 이동 0, 운반 0.
- 투과율은 데이터이며, 문을 닫는 같은 **행동이 간선 상태를 바꿔** 번짐의 모양을 바꾼다.

---

## 3. 매질 네 가지

매질이 번짐의 **알고리즘**을 정하고, 개체는 그 알고리즘의 매개변수 묶음이다.

| 매질 | 번지는 방식 | 예 |
|---|---|---|
| **공기** | 이웃 장소로 확산. 거리에 따라 약해짐 | 냄새, 연기 |
| **운반** | 운반체(인물, 신발, 물건)가 **간 곳**으로 | 발바닥 먼지, 음식물 자국 |
| **자력 이동** | 개체가 스스로 먹이·원천을 향해 이동 | 벌레 |
| **흐름** | 중력과 흐름 방향을 따라 | 물, 누수 |

슬라이스에서는 **공기, 운반, 자력 이동** 세 가지만 쓴다.

---

## 4. 번짐 개체 정의

| 필드 | 뜻 |
|---|---|
| `medium` | 위 네 매질 중 하나 |
| `reach` | 원천에서 최대 몇 칸까지 (간선 수) |
| `attenuation` | 한 칸마다 줄어드는 강도 (정수, 천분율) |
| `rate` | 경과 시간당 진행 속도 |
| `needs` | 유지에 필요한 것 (원천, 먹이, 습기). 없으면 감쇠 |
| `stimulus` | 만들어 내는 감각 자극 (후각, 시각, 청각, 촉각) |
| `spawns` | 조건이 맞으면 일으키는 다른 개체·상태 (연결) |
| `suppressed_by` | 약화시키는 행동·물품·상태 (환기, 방충제, 문 닫기) |
| `on` / `emits` | 상태 사슬용 패턴 (기반층-명세 0-3) |

---

## 5. 전파 규칙 (난수 없음)

모든 값은 정수이고 같은 입력이면 같은 결과가 나온다.

### 5-1. 공기 확산

```
이웃 강도 = 원천 강도 × 간선 투과율(공기) ÷ 1000 − attenuation
```

- 강도가 0 이하이거나 `reach`를 넘으면 멈춘다.
- 강도가 각 특징의 단계 임계를 넘으면 해당 장소의 상태 단계가 오른다.

### 5-2. 운반

- 운반체가 **이동한 경로**를 따라 개체가 옮겨진다. 경로는 인물의 행동·일과·습관에서 나온다 (예: 귀가 후 신발을 벗는 위치).
- 옮겨지는 양은 운반체가 가진 양에서 일정 비율로 줄어든다.
- 따라서 같은 오염도 **플레이어의 습관에 따라 다른 곳에 남는다**.

### 5-3. 자력 이동

- 이동 방향은 **유인 기울기**(먹이·원천의 강도)가 가장 높은 이웃이다.
- 기울기가 같으면 **장소 번호가 작은 쪽**으로 간다 (무작위가 아닌 고정 규칙).
- 칸당 이동에 시간 비용이 들고, `needs`가 없으면 개체 강도가 줄어 소멸한다.

### 5-4. 진행도

- 개체의 강도는 정수 진행도(0~1000)로 쌓이고, 임계를 넘으면 **상태 단계**가 오른다. 단계를 바꾸는 것은 세계 상태이고 규칙은 효과를 요청만 한다.
- 가중치는 **원천의 현재 정도**에서 나온다 (더러울수록 빨리 번진다).

### 5-5. 부재 보정과의 관계

- 부재 시에는 같은 규칙을 큰 시간 간격으로 돌린다. 시간 간격이 크면 **임계 도달 시각을 계산해 단계별로 처리**한다.
- 마지막으로 본 상태 +1단계 상한을 적용한다 (보고서 4-6).

---

## 6. 연결된 개체: 계통

한 원천에서 개체들이 연결되는 방식은 세 가지다.

1. **파생(`spawns`)**: 조건이 맞으면 다른 개체를 일으킨다. 예: 부패 단계 2 → 냄새, 단계 3 → 벌레.
2. **의존(`needs`)**: 한 개체가 다른 개체나 상태에 기대어 산다. 벌레는 먹이가 있어야 하고, 곰팡이는 습기가 있어야 한다.
3. **억제(`suppressed_by`)**: 다른 상태·행동이 약화시킨다. 환기는 냄새를 줄이고, 문 닫기는 벌레의 이동을 막는다.

**계통 예: 상한 음식**

| 단계 | 개체 | 매질 | 연결 |
|---|---|---|---|
| 원천 | 상한 음식 (냉장고) | — | 부패 단계 오름 |
| 1 | 냄새 | 공기 | 단계 2에서 `spawns`. 환기로 억제 |
| 2 | 벌레 | 자력 이동 | 단계 3에서 `spawns`. 음식을 `needs`. 문 닫기·방충제로 억제 |
| 3 | 벌레의 번식 | 자력 이동 | 먹이가 있는 다른 장소(쓰레기통)로 계통 확장 |
| 4 | 습기와 곰팡이 | 흐름/공기 | 냉장고 고장이나 누수 같은 별개 원천과 만나면 연결 |

사슬 길이 상한(4단계) 안에서 계통을 설계한다.

**계통은 인지의 대상이기도 하다.** 인지 2단계("이해함")는 개별 개체가 아니라 **계통의 연결**을 알아보는 것이다 (냄새와 벌레가 같은 원천에서 왔다).

---

## 7. 다른 시스템과의 연결

| 시스템 | 연결 |
|---|---|
| 감각 | 개체의 `stimulus`가 자극이 되고 인물의 민감도가 곱해진다 |
| 인지 | 자극·증상이 해금 조건. 계통 연결 이해가 2단계 |
| 행동 | 문 닫기, 환기, 방충, 청소가 간선 상태·`suppressed_by`·원천 상태를 바꾼다 |
| 자원 | 방충제·환기용품 같은 소모품이 억제 수단 |
| 습관 | 문을 닫는 습관, 신발 두는 위치가 번짐의 모양을 바꾼다 |
| 인물 | 운반체이자 감각 주체 |
| 이벤트 | 계통 단계가 이벤트 조건 (벌레 → 손님 방문 시 민망함) |

---

## 8. 슬라이스 범위

| 항목 | 슬라이스 |
|---|---|
| 번짐 개체 | **3종**: 냄새(공기), 벌레(자력 이동), 발바닥 먼지(운반) |
| 장소 | 현관, 주방(냉장고), 거실 정도 (3~4개) |
| 간선 종류 | 열린 통로, 문(냉장고·방), 벽 |
| 행동 | 문 닫기/열기, 환기, 닦기 |
| 계통 | 상한 음식 하나 (냄새 → 벌레) |

---

## 9. 미정 사항

1. 개체의 강도를 **정수 진행도 하나**로 둘지, 장소별 강도를 따로 저장할지 (현재안: 장소별 저장).
2. 운반체의 범위: 인물만 둘지, 신발·택배 같은 **물건도 운반체**로 둘지 (현재안: 인물과 신발).
3. 간선 상태(문 열림/닫힘)를 **슬라이스에서 플레이어가 조작**하게 할지 (현재안: 예).
4. 자력 이동 개체의 **소멸 조건**과 부재 중 처리.
5. 흐름 매질은 슬라이스 밖으로 미루는 것이 맞는지.
