# 번짐 명세 (변화 규칙의 하위 설계, 초안 2)

오염과 부패가 장소를 넘어 퍼지는 방식을 정의한다. 변화 규칙의 일부이므로 **난수를 쓰지 않는다** (기반층-명세 0-5). 상태: 초안.

---

## 1. 핵심 개념

- 번짐은 상태의 속성이 아니라 **번짐 개체**가 일으킨다. 냄새, 벌레, 먼지, 물, 곰팡이는 각자 번지는 방식과 범위가 다르다.
- 번짐 개체는 하나로 끝나지 않고 **연결**된다. 부패한 음식 하나가 냄새를 내고, 벌레를 부르고, 벌레가 다른 곳에서 번식한다. 이 묶음을 **계통**이라 한다.
- **개체는 위치와 양을 가진다. 장소별 강도는 저장하지 않고, 개체의 위치에 가까운 정도로 계산한다** (파생값).
- 개체 정의(범위, 매질, 의존, 연결)는 전부 **데이터**다. 엔진은 개체 이름을 모른다.

| 용어 | 뜻 |
|---|---|
| 원천 | 번짐의 근원이 되는 상태 (상한 음식, 젖은 신발) |
| 번짐 개체 | 원천에서 생겨 퍼지는 것 (냄새, 벌레, 먼지, 곰팡이 …) |
| 매질 | 개체가 이동하는 방식 (공기, 운반, 자력 이동, 흐름) |
| 통로 | 장소 그래프의 간선. 개체가 지나갈 수 있는 길 |
| 운반체 | 번짐을 받거나 옮기는 물체. **고정**과 **가변**이 있다 (5장) |
| 계통 | 하나의 원천에서 이어져 나오는 개체들의 묶음 |

---

## 2. 장소 그래프

- **노드**는 장소(PLC), **간선**은 통로다.

| 종류 | 예 | 가변 상태 |
|---|---|---|
| 열린 통로 | 현관-거실 사이 | 없음 |
| 문 | 방문, 냉장고 문 | 열림 / 닫힘 (**자동**) |
| 벽 | 방과 방 | 없음 |
| 배수·환기구 | 욕실 배수구, 환풍기 | 막힘 / 열림 |

- 간선마다 **매질별 투과율**(0~1000)을 가진다. 예: 닫힌 문은 공기 100, 자력 이동 0.
- **문 상태는 자동**이다. 기본은 닫힘이고, 인물이 지나갈 때 열렸다가 닫힌다. 플레이어가 문을 직접 조작하지 않는다.
- 문 상태에 영향을 주는 것은 인물의 일과·습관과 환경 요인이다 (10장).
- 플레이어가 직접 하는 것은 **환기(창문 열기)** 같은 행동이며, 그 결과가 투과율과 환경에 영향을 준다.

---

## 3. 매질 네 가지

매질이 번짐의 **알고리즘**을 정하고, 개체는 그 알고리즘의 매개변수 묶음이다.

| 매질 | 번지는 방식 | 예 |
|---|---|---|
| **공기** | 원천에서 거리에 따라 약해지며 퍼짐 | 냄새, 연기 |
| **운반** | 가변 운반체가 **접촉하고 이동한 곳**으로 | 발바닥 먼지, 음식물 자국 |
| **자력 이동** | 개체가 스스로 먹이·원천을 향해 이동 | 벌레 |
| **흐름** | 물이 아래로 흐르며 번짐 (엎지른 물, 누수) | 슬라이스 밖 |

슬라이스에서는 **공기, 운반, 자력 이동** 세 가지만 쓴다.

---

## 4. 번짐 개체 정의

| 필드 | 뜻 |
|---|---|
| `medium` | 매질 |
| `reach` | 원천에서 최대 몇 칸까지 |
| `attenuation` | 가까움에 따라 줄어드는 정도 (거리당, 천분율) |
| `growth` / `decline` | 조건이 맞을 때의 증가 속도 / 조건이 깨졌을 때의 감소 속도 |
| `needs` | 유지에 필요한 것 (원천, 먹이, 습기). 없으면 감소 |
| `stimulus` | 만들어 내는 감각 자극 (후각, 시각, 청각, 촉각) |
| `spawns` | 조건이 맞으면 일으키는 다른 개체·상태 (연결) |
| `suppressed_by` | 약화시키는 행동·물품·상태 (환기, 포획 도구) |
| `on` / `emits` | 상태 사슬용 패턴 (기반층-명세 0-3) |

**개체의 저장 상태**: `위치`(장소 또는 운반체)와 `양`(정수). 이것만 저장한다.

## 5. 운반체

세계의 물체는 모두 운반체다. 번짐을 **받고(수용)** 또는 **옮긴다(전달)**.

| 구분 | 설명 | 예 |
|---|---|---|
| **고정 운반체** | 움직이지 않는다. 번짐을 받아 쌓고, 그 장소의 상태가 된다 | 벽, 바닥, 붙박이 부엌, 붙박이 옷장 |
| **가변 운반체** | **사람 혼자 옮길 수 있는 모든 것** (`mobility: portable`). 번짐을 받아 **다른 곳으로 옮긴다** | 인물, 신발, 가방, 택배, 옷, 그릇 |

### 5-1. 전달은 상호작용의 가능성에 따라

- 전달은 두 운반체가 **접촉 가능한 관계**일 때만 일어난다. 접촉 관계는 배치와 행동에서 나온다.

| 접촉 종류 | 예 |
|---|---|
| 밟음 | 신발 ↔ 바닥 |
| 쥠·착용 | 인물 ↔ 가방·옷 |
| 담김·포개짐 | 그릇 ↔ 냉장고 선반, 옷 ↔ 옷장 |
| 같은 표면 위 | 식탁 위 물건끼리 |

- 접촉 종류마다 **전달률**(천분율)을 데이터로 가진다.
- 전달량 = 보유량 × 전달률. 같은 입력이면 같은 결과다 (난수 없음).
- 접촉 관계는 `놓인 곳` 속성에서 계산하고, 새로 접촉이 생기면 `contact` 사건을 낸다.

### 5-2. 예

```
신발(가변, 먼지 보유) --밟음--> 현관 바닥(고정)
신발 --착용(인물)--> 인물이 이동 --밟음--> 거실 바닥(고정)
```

- 같은 오염도 **인물이 어디를 걷고 어디에 신발을 두는가**에 따라 남는 곳이 달라진다. 규칙은 결정적이고 결과는 습관에 따라 달라진다.

## 6. 전파 규칙 (난수 없음)

### 6-1. 가까움에 따른 강도 (공기)

```
장소 P에서의 강도 = 개체 양 × (경로상 간선 투과율의 곱) ÷ 1000^n − attenuation × 거리
```

- 거리는 개체 위치에서 P까지의 **최단 경로**(간선 수)다. 투과율이 낮은 간선을 지나면 크게 줄어든다.
- 강도가 0 이하이거나 `reach`를 넘으면 0이다.
- 이 값은 **읽을 때 계산하는 파생값**이다. 저장하지 않는다.
- 단계 임계를 넘으면 해당 장소의 **상태 단계**가 오른다 (단계 변경은 세계 상태가 한다).

### 6-2. 운반

5장의 접촉 규칙을 따른다. 시간 흐름이 아니라 **접촉 사건**에서 전달이 일어난다.

### 6-3. 자력 이동

- 이동 방향은 **유인 기울기**(먹이·원천의 강도)가 가장 높은 이웃이다. 같으면 장소 번호가 작은 쪽이다 (고정 규칙).
- 칸당 이동에 시간 비용이 든다.

### 6-4. 개체의 증감

```
양(t + dt) = 양(t) + growth × 충족 × dt − decline × 미충족 × dt − 억제량
```

- `충족`은 `needs`가 만족되는 시간, `미충족`은 깨진 시간이다.
- **먹이를 잃으면** 미충족이 되어 양이 줄다가 0이 되면 소멸한다.
- **억제량**은 환기, 포획 도구 같은 `suppressed_by`의 효과다.

### 6-5. 포획 도구 (예: 간장종지 덫)

- 포획 도구는 **물품(ITM)** 이며, 놓아서 쓰면 **설치형 오브젝트**가 된다 (`install`). 같은 물건이 보유 중일 때와 설치됐을 때 모습이 다르다.
- 설치되면 개체를 시간당 일정량 줄인다.
- **용량이 있다**: 가득 차면 효과가 멈춘다. 이는 유한 자원(풀)과 같은 구조다.
- **비우기(`empty`)는 삭제가 아니다.** 내용물은 사라지지 않고 **보관**으로 옮겨진다 (6-7).
- 부재 중에도 용량이 찰 때까지는 작동하고, 찬 뒤에는 멈춘다.

### 6-6. 부재 보정

- 같은 규칙을 큰 시간 간격으로 돌린다. 시간 간격이 길면 **임계 도달 시각(굶어 소멸, 덫이 참, 단계 도달)을 계산해 구간별로 처리**한다.
- 증가하는 쪽에는 "마지막으로 본 상태 +1단계" 상한을 적용한다 (보고서 4-6).
- **감소하는 쪽에는 상한을 두지 않는다.** 먹이가 사라진 벌레가 자연히 줄어드는 것은 플레이어에게 불리하지 않기 때문이다.

### 6-7. 물건 보존과 거래

- **물건은 삭제되지 않는다.** 버리거나 비워도 사라지지 않고 **보관**으로 옮겨진다 (쓰레기통, 봉투, 창고 같은 장소). 보존 점검은 자원뿐 아니라 물건의 총량에도 적용된다.
- 물건이 플레이어 세계를 떠나는 길은 **판매(양도)** 하나다. 중고 거래(당근 유형)로 넘어가며 돈을 받는다. 양도된 물건은 거래 쪽에 존재하므로 총량은 보존된다.
- 보관된 물건도 원천이 될 수 있다 (예: 보관된 음식물). 별도 규칙 없이 기존 규칙으로 처리된다.
- 판매 기능은 거래(시장) 시스템이 필요하므로 **슬라이스 밖**이다 (시스템-명세 8).

## 7. 연결된 개체: 계통

1. **파생(`spawns`)**: 조건이 맞으면 다른 개체를 일으킨다. 예: 부패 단계 2 → 냄새, 단계 3 → 벌레.
2. **의존(`needs`)**: 한 개체가 다른 개체나 상태에 기대어 산다. 벌레는 먹이가 있어야 한다.
3. **억제(`suppressed_by`)**: 다른 상태·행동이 약화시킨다. 환기는 냄새를, 포획 도구는 벌레를 줄인다.

**계통 예: 상한 음식**

| 단계 | 개체 | 매질 | 연결 |
|---|---|---|---|
| 원천 | 상한 음식 (냉장고) | — | 부패 단계 오름 |
| 1 | 냄새 | 공기 | 단계 2에서 `spawns`. 환기로 억제 |
| 2 | 벌레 | 자력 이동 | 단계 3에서 `spawns`. 음식을 `needs`. 먹이 소멸·포획 도구로 감소 |
| 3 | 벌레 번식 | 자력 이동 | 먹이가 있는 다른 장소로 계통 확장 |

사슬 길이 상한(4단계) 안에서 설계한다. **계통은 인지의 대상**이다. 인지 2단계("이해함")는 냄새와 벌레가 같은 원천에서 왔다는 연결을 알아보는 것이다.

## 8. 다른 시스템과의 연결

| 시스템 | 연결 |
|---|---|
| 감각 | 개체의 `stimulus`가 자극이 되고 인물의 민감도가 곱해진다 |
| 인지 | 자극·증상이 해금 조건. 계통 연결 이해가 2단계 |
| 행동 | 환기, 포획 도구 설치·비우기, 닦기, 버리기가 억제·원천 상태를 바꾼다 |
| 자원 | 포획 도구의 용량, 소모품 |
| 습관 | 신발을 두는 위치·동선이 운반 경로를 만든다 |
| 인물 | 가변 운반체이자 감각 주체 |
| 이벤트 | 계통 단계가 조건 (벌레 → 손님 방문 시 민망함) |

## 10. 확장 후보: 창문과 바람

환경 요인이 통로 상태를 바꾸는 예다. **슬라이스에는 넣지 않는다.** 구조는 이미 지원한다.

- 창문은 외부 노드로 이어지는 **간선**이고 열림/닫힘이 있다 (플레이어의 환기 행동).
- 바람은 **개입(날씨 이벤트)** 이다. 조건: 창문 열림 + 바람 세기 ≥ 임계 + 문 열림.
- 결과는 **인과 규칙**이다: 문이 강하게 닫힘 → 청각 자극(쾅), 문 상태 변경(공기·벌레 차단), 때로는 놀람 같은 상태.
- 의미: 환기 습관이 문 상태와 소리와 번짐을 한꺼번에 바꾼다. 시스템의 연결에서 사건이 나오는 좋은 예다.

## 11. 결정 현황

**해결됨**

1. 접촉 종류와 전달률: 사전(`data/vocab/00-core.json`)에 초안을 썼다. 전달률은 전부 임시값(`tuned:false`).
2. 가변 운반체: 사람 혼자 옮길 수 있는 모든 것 (`mobility: portable`).
3. 포획 도구: 물품이며 설치형 오브젝트로도 쓴다. 비우기는 삭제가 아니라 보관 (6-5, 6-7).

**보류**

4. 문 자동 규칙 (닫히는 시간, 습관의 영향).

**미정**

5. 개체 양의 단위와 단계 임계값의 초기 표 (`tuned:false`로 시작).
6. 창문·바람을 넣는 시점 (슬라이스 이후 제안).
7. 보관 장소(쓰레기통 등)의 종류와 수거·배출 규칙.
8. 거래(중고 판매) 시스템의 범위.
