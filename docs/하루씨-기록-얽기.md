# 하루씨 기록 얽기 (조각, 궤도, 데이터로 가는 길)

작성일 2026-11-17 · 상태: **초안** (조각 표는 지금까지의 기록을 옮긴 것, 교차점과 관리 규칙은 제안) · 근거: `하루씨-해부표.md`, `하루씨-감정-인터뷰.md`, `인터뷰-형식.md`, `결정-기록.md`

인터뷰는 하루씨를 **만드는 시작점**이다. 답이 쌓여 기본 데이터가 되고, 거기서 감정·과거·역할이 뻗어 나가 서로 이어진다. 이 문서는 (1) 지금까지 모인 것을 **조각**으로 나눠 번호를 붙이고, (2) 조각을 **궤도**로 얽어 교차점을 찾고, (3) 조각이 **세 가지 데이터**(인격, 사건, 외부 사건)로 가는 길과 (4) 그 연결을 끝까지 유지하는 **관리 규칙**을 적는다.

**층 구분 (작가 확정)**: 모든 궤도로 이어지는 것은 **작가 쪽 기록**(이 문서)이다. 게임이 돌 때 읽는 것은 여기서 뽑은 **파라메터**다(하루는 단독 시스템, 결정-기록).

## 5. 세 가지 데이터로 가는 길

인터뷰가 먼저 정하는 것은 **첫 인격 데이터, 사건 데이터, 외부 사건 데이터 몇 개**다 (작가). 그 뒤는 시스템이 돌며 채운다.

| 데이터 | 들어가는 것 | 재료가 되는 조각 | 아직 없는 것 |
|---|---|---|---|
| **인격** (인물 파라메터) | 감각, 허용 한계, 습관, 버릇, 감정의 기준값, 좋아하는 것 | H-014, H-015, H-020~022, H-024~026, H-028 | 감각과 허용 한계의 수치, 감정 수치(해부표 12장), 버릇이 켜지는 조건 |
| **사건** (이미 일어난 일, 흔적의 근거) | 5살의 이혼과 도피 · 어머니와 둘이 산 시절 · 어머니의 죽음(3주 전) · 장례(아버지를 부르지 않음) | H-005, H-007, H-008, H-010~013, H-027 | 사건마다 집에 남은 흔적(물건), 어머니의 죽음에 대한 지금 상태(진행 중인지, 접어 둔 것인지) |
| **외부 사건** (4a 카드, 앞으로 일어나는 일) | 아버지의 전화 · 후배와 카페 · 회사 일(리팩토링) · 퇴근길 나물 할머니 · 출근길 동료 | H-017, H-019, H-023, H-024, H-027 | 발생 조건과 시점, 각 사건이 내면의 무엇을 움직이는지 |

## 6. 관리 규칙 (제안): 기록을 끝까지 데리고 가는 법

인터뷰는 시작이고, 모든 것이 인터뷰로 정해지지는 않는다. 그래서 **원천을 가리지 않는 한 줄의 사슬**로 관리한다.

```
원천 (인터뷰 답 · 시나리오 원문 · 작가의 말)
  → 조각 (H-번호, 궤도 표시, 고치지 않음)
    → 데이터 항목 (인격 파라메터 · 사건 · 외부 사건 카드 · 문장 자리)
      → 게임에서 일어난 것 (기록)
```

1. **조각 번호는 끝까지 간다.** 조각이 데이터가 될 때 패치의 `why`에 조각 번호를 적는다 (예: "H-022: 설거지를 물만 받아 둔다"). `why`는 이미 필수이므로 형식을 바꾸지 않는다.
2. **조각에서 오지 않은 값도 출처를 밝힌다.** 인물의 값인데 조각이 없으면 둘 중 하나다: 임시값(`tuned:false`)이거나, 시험으로 보정한 값(보정 이유를 `why`에). 보정은 조각을 고치지 않고 데이터만 고친다.
3. **거꾸로도 짚는다.** 조각 표에 "쓰인 곳" 칸을 더해 어느 데이터에 들어갔는지 적는다. 쓰인 곳이 없는 조각은 아직 안 쓴 재료이고, 조각 없는 인물 값은 근거를 물어야 할 값이다. 조각이 많아지면 이 대조를 명령으로 만든다 (아직 만들지 않음).
4. **추정은 조각이 아니다.** 제 읽기(4장)는 작가가 확인해야 조각이 된다. 확인되지 않은 읽기로는 데이터를 만들지 않는다.
5. **질문은 조각에서 자란다.** 새 질문은 3장의 빈 곳이나 4장의 씨앗에서 고른다. 답은 `Q-번호`로 인터뷰 기록에 원문 그대로 남고, 여기에 조각으로 옮긴다.
6. **인터뷰가 정하지 않는 것**: 물건의 변화 규칙, 집의 상태, 수치의 보정, 게임 중에 생기는 일. 이것들은 시스템과 시험이 정하고, 인물 조각과 닿는 자리(예: 설거지가 쌓이는 속도와 H-022)에만 조각 번호를 단다.

## 7. 한계

- 조각 표는 해부표와 인터뷰 기록에서 옮긴 것이다. 시나리오 원문과 직접 대조하지 못했다.
- 궤도 표시는 제가 붙였다. 작가의 확인이 필요하다.
- 조각과 데이터의 대조는 아직 손으로 한다. 도구가 없다.
- 인물 데이터의 형식(L1 인물)이 아직 컴파일러에 없어서, 조각이 실제 데이터 항목이 되는 길은 형식이 정해진 뒤에 확인할 수 있다.
