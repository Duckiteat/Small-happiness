# 음식 변화 모델

작성일 2026-11-06 · 상태: **고정안** (2·3장과 8장의 답은 작가 확정, 4·5·6장은 제안) · 근거: `축과-층위.md` 4장(속도 계산, 음식 상태의 이름), `데이터-형식.md` 5-2(진행 법칙), `결정-기록.md` 4장

음식이 어떻게 변하는지를 정한다. 첫 데이터(패치 0001)는 모든 음식에 같은 축 하나("상함": 신선 → 시들함 → 상함)와 날짜만 두었다. 그래서 우유가 "시들"고 김치가 "상하는" 말이 안 되는 결과가 나왔다. 이 문서가 그 자리를 대신한다.

**원칙**: 음식은 **자기에게 일어나는 과정의 축만** 가진다. 과정의 속도는 **조건**(보관·수분·가공·온도)이 정한다. 상태의 이름("먹을 수 있음", "찌개용", "못 먹음")은 축의 조합으로 계산한다. 단어는 국어사전, 수치는 공식 자료를 따르고, 없으면 추정으로 표시한다 (6장).

---

## 1. 결론

- 조건 네 가지를 작가가 정했다 (2장). 이것이 모든 음식의 속도 입력이다.
- **냉동에서는 상하지 않는다.** 부패·시어짐·발효·곰팡이는 멈추고, 수분이 빠지는 것(냉동화상)만 진행한다 (2-4).
- **뜨거운 채로 넣고 닫으면** 식는 동안 용기 안 습도가 올라 표면에 물이 맺힌다(결로). 이 과정 자체를 축으로 둔다 (2-2, 3장).
- 엔진에는 **양 저장**(축마다 0~1000으로 쌓이는 양, 단계는 양에서 계산)이 필요하다. 뚜껑을 닫거나 냉장고에서 꺼내는 순간 남은 시간이 바뀌기 때문이다 (5장).

## 2. 조건 (작가 확정, 2026-11-06)

### 2-1. 보관

| 단계 | 뜻 | 바뀌는 길 |
|---|---|---|
| 멸균 | 들어올 때 이미 미생물이 없게 처리된 제품 (멸균우유, 레토르트) | 뜯으면 → 오픈. 다시 멸균으로 돌아가지 않는다 |
| 살균 | 들어올 때 살균 처리된 제품. 냉장이 필요하다 (일반 흰우유, 요거트) | 뜯으면 → 오픈 |
| 밀폐 | 뚜껑을 꼭 닫은 용기. **요리해서 담고 닫아도 밀폐다** | 열면 → 오픈 |
| 반밀봉 | 랩, 대충 덮은 뚜껑, 봉지 입구 묶음, 배달 용기 | 닫으면 → 밀폐, 벗기면 → 오픈 |
| 오픈 | 덮지 않음 | 덮거나 닫으면 → 반밀봉·밀폐 |

- **멸균·살균은 제품이 들어올 때의 상태**다. 집에서 만들 수 없다. 한 번 뜯으면 끝이다.
- 보관은 바뀌는 **상태**다. 하루씨의 행동(뚜껑 닫기, 랩 씌우기)이 바꾼다.

### 2-2. 수분 상태

**용기(그릇·박스) 안쪽과 음식 표면 기준**이다. 음식이 원래 가진 물기가 아니라, 그 음식이 놓인 작은 환경의 물기다.

| 단계 (낮음 → 높음) | 예 |
|---|---|
| 마름 | 뚜껑 없이 둔 밥 표면, 말라붙은 소스 |
| 꾸덕 | 요거트, 식어서 굳은 튀김 표면 |
| 촉촉 | 갓 담은 반찬, 물기 있는 채소 |
| 액체 | 우유, 김치 국물, 두부 충전수 |

**바뀌는 길**
- 오픈·반밀봉으로 냉장하면 표면이 마른다 (촉촉 → 꾸덕 → 마름). 냉장고 안 공기가 건조하기 때문이다.
- **뜨거운 채로 넣고 닫으면 식으면서 습도가 오른다**: 따뜻한 공기가 품는 수증기가 식으면서 뚜껑과 벽에 맺히고(결로) 표면으로 떨어진다 → 수분 상태가 올라간다 (예: 꾸덕 → 촉촉). 튀김이 눅눅해지는 것이 이것이다.

**찾아온 개념 (근거)**
- **결로**: 공기가 품을 수 있는 수증기 양은 온도가 내려가면 줄어든다. 넘치는 만큼 차가운 면에 물로 맺힌다. 일반 물리 지식이며, 음식 보관과의 관계를 직접 다룬 공식 자료는 이번에 찾지 못했다.
- **위험 온도대와 2단계 식힘** (미국 FDA 식품 규정, 요식업 기준): 조리한 음식은 57℃(135°F)에서 21℃(70°F)까지 2시간, 다시 5℃(41°F)까지 4시간 안에 식혀야 한다. 그 사이 온도에서 세균이 빨리 는다. 식약처는 세균성 식중독균이 32~43℃에서 가장 활발하다고 밝혔다 (기사 인용, 원문 미확인).
- 게임에서는 이것을 **식는 중** 축으로 둔다 (3장). 이 축과 수분 상태가 저절로 바뀌는 것(마르기·결로)은 엔진 2차에서 넣는다. 1차에서는 수분 상태를 살 때의 값으로 두고 속도의 입력으로만 쓴다. 뜨겁게 넣고 닫으면 ① 식는 동안 부패가 빨라지고 ② 수분 상태가 오른다.

### 2-3. 가공

밖에서 가공된 제품인지가 아니라, **지금 이 음식이 어떤 모양인가**다. 표면이 넓을수록 마르기도, 상하기도 빠르다.

| 단계 | 예 |
|---|---|
| 통째 | 사과 한 알, 대파 한 단, 두부 한 모 |
| 토막 | 반 자른 두부, 큼직하게 썬 무 |
| 채·큐브 | 채 썬 양배추, 깍둑 썬 두부, 슬라이스 햄 |
| 다짐 | 다진 마늘, 간 고기 |

- **조리됨은 가공 단계가 아니다.** 조리는 여러 재료가 합쳐지는 일이므로, 조리한 음식은 **새로운 음식 하나("조리됨")**가 된다. 남은 치킨, 찌개, 볶음밥은 모두 조리된 음식의 종류다.

### 2-4. 온도

| 단계 | 뜻 |
|---|---|
| 냉동 | **상하지 않는다.** 부패·시어짐·발효·곰팡이 속도 0. 수분이 빠지는 것만 진행한다 |
| 냉장 | 기본 |
| 실온 | 계절에 따라 다르다. **여름 26~30℃ → 25℃ 이상 구간, 봄·가을 15~20℃ → 15~20℃ 구간, 겨울 5~10℃ → 5~10℃ 구간** (작가, 범위표의 5℃ 구간에 맞춤). 냉장은 0~5℃, 냉동은 0℃ 미만 구간 |

**냉동에서 수분이 빠지는 것 (냉동화상)**: 얼음이 물을 거치지 않고 바로 수증기가 되어(승화) 표면이 마르고 변색된다. 안전 문제가 아니라 품질 문제다. 표면이 넓을수록(채·다짐), 공기에 닿을수록(오픈·반밀봉), 냉동고 온도가 오르내릴수록 빠르다. 진공·밀폐가 가장 잘 막는다 (해외 소비자 자료 인용, 공식 자료 미확인).

## 3. 축 (작가 확정)

음식은 아래 축 중 **자기에게 일어나는 것만** 가진다. 단계 이름은 국어사전 뜻풀이로 확인한 뒤 확정한다 (6장).

| 축 | 단계 (제안) | 과정 | 해당하는 음식 |
|---|---|---|---|
| 부패 | 신선 → 쉼 → 상함 → 썩음 | **쉼은 산화·발효로 시어지는 단계이고, 그 뒤 부패로 이어진다** (작가) | 두부, 햄, 조리된 음식, 계란(아주 느림) |
| 시어짐 | 신선 → 새큼 → 시큼 → 덩어리짐 | 젖산·산패. **덩어리짐은 액체 속에 곰팡이·균류 덩어리가 떠다니는 형태** (작가) | 우유, 요거트 |
| 익음 | 덜 익음 → 알맞게 익음 → 시어짐 → 물러짐 | 발효 | 김치 |
| 시듦 | 싱싱 → 시듦 → 쭈글·짓무름 | 조직의 물이 빠짐 | 상추, 대파, 사과 |
| 곰팡이 | 없음 → 점 → 번짐 | 곰팡이·효모막 (김치의 골마지 포함) | 공기에 닿는 것 대부분 |
| 수분 상태 | 마름 → 꾸덕 → 촉촉 → 액체 | 2-2의 환경 (축이자 다른 축의 입력) | 모두 |
| 식는 중 | 뜨거움 → 미지근 → 식음 | 2-2의 위험 온도대 | 조리된 음식 (넣을 때만) |

- **"시들함"은 시듦 축에만 있다.** 우유와 김치는 시들지 않는다.
- **김치는 상하지 않고 익는다.** 시어지면 찌개용이 되고, 물러지거나 골마지가 번지면 못 먹는다.
- 각 축은 단계마다 **감각 기원**(냄새·보임·만짐)을 가진다 (`예시-사과.md`의 감각 기원 표처럼). 5층 지각이 이것을 읽는다.

## 4. 속도 (제안, `축과-층위.md` 4장 그대로)

- **축의 속도 = 기본 속도 × 보관 계수 × 수분 계수 × 가공 계수 × 온도 계수** (×100 정수, `tuned:false`).
- **같은 조건도 축마다 계수가 다르다.** 예: 밀폐는 시듦을 크게 늦추고 부패는 조금만 늦춘다. 수분 상태 "액체·촉촉"은 부패를 빠르게, "마름"은 곰팡이를 늦춘다.
- **냉동의 온도 계수는 부패·시어짐·익음·곰팡이에 0**, 시듦·수분 상태(마름 쪽)에만 0보다 크다.
- 음식마다 다른 것은 **기본 속도**(그 음식의 물성)와 **처음 조건**(4장 표)뿐이다. 규칙을 음식마다 따로 쓰지 않는다.

## 5. 엔진에 필요한 것

> **1차 구현 (2026-11-06)**: 1·2·4번은 됐다 (`src/core/progress.ts`, 패치 0002). 3번(축 사이의 연결: 결로·마르기)과 식는 중 축, 표시 기한은 2차.

1. **양 저장**: 축마다 0~1000의 양을 저장하고 단계는 경계에서 계산한다 (미뤄 둔 결정, `축-구현-순서.md` 층 2 첫 작업).
2. **진행 법칙**: 위 속도식. 조건(보관·수분·가공·온도)이 바뀌는 순간 남은 시간을 다시 계산하고, 임계를 넘는 정확한 시각을 예약한다. 간격과 상관없이 결과가 같은 성질은 그대로 지킨다.
3. **축 사이의 연결**: 식는 중 → 수분 상태(결로), 수분 상태 → 다른 축의 계수. 연결은 조건 계수로만 건다 (새 결합 종류를 만들지 않는다).
4. **행동**: 뚜껑 닫기·랩 씌우기(보관), 냉동실로 옮기기(온도). 지금의 `offers`로 표현한다.

## 8. 정한 것 (작가, 2026-11-06)

1. **축 일곱 개와 단계 이름은 맞다.** 쉼 = 산화·발효로 시어짐 → 부패로 이어짐. 덩어리짐 = 액체 속에 균 덩어리가 떠다님.
2. **실온 계절 구간**: 여름(26~30℃) · 봄·가을(15~20℃) · 겨울(5~10℃), 범위표의 구간에 맞춘다 (2-4).
3. **슬라이스는 채·큐브** (두께가 얇기 때문).
4. **처음 조건은 구매와 붙어 있다.** 물건마다 "살 때의 상태"(보관·수분·가공·온도)를 정의에 두고, 들여놓을 때 그 상태로 시작한다.
5. **유통기한(표시 기한)과 썩는 것은 다른 개념으로 돌린다.** 표시 기한은 포장에 적힌 정보이고(하루씨가 보고 판단할 수 있다), 썩는 것은 위의 축이 진행하는 물리적 과정이다. 표시 기한은 다음에 구매·지각과 함께 넣는다.
