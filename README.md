# Small-happiness

**당신의 하루가 소박한 행복이 되기를.** — 시스템에서 태어나는 생활 이야기

일하는 직장인의 하루를 살아 보는 스토리텔링 기반 생활 시뮬레이션. 콘텐츠는 시스템에서 나오고, 작가는 그 순간의 문장을 쓴다.

## 개발

```sh
npm install
npm test          # 테스트
npm run typecheck # 타입 검사
```

Node 22.18 이상이 필요하다. TypeScript를 빌드 없이 바로 실행한다.

## 구성

| 경로 | 내용 |
|---|---|
| `src/core/` | 시뮬레이션 코어 (번호, 상태 키, 사건, 기록, 사전). 입출력 없음 |
| `src/node/` | 파일을 읽는 어댑터 |
| `data/vocab/` | 사전 (게임이 쓰는 모든 단어) |
| `test/` | 테스트 |
| `docs/` | 기획과 설계 문서 |

## 문서

- `docs/기획보고서-v2.md` — 기획 보고서
- `docs/결정-기록.md` — 결정 현황
- `docs/시스템-명세.md` — 시스템 분리와 계약
- `docs/기반층-명세.md` — 번호, 상태 키, 사건, 기록, 난수, 시계, 저장
- `docs/번짐-명세.md` — 오염이 퍼지는 방식
- `docs/사전-명세.md` — 사전(통제 어휘)
- `docs/DB-개념-이식.md` — 별도 프로젝트에서 가져온 설계 개념
